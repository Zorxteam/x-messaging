# GIFs Directory

Place your GIF files here. The filenames should match those specified in `messages.json`.

Example files:
- rocket.gif
- fire.gif
- strong.gif
- hundred.gif
- lets_go.gif
- fist_bump.gif
- moon.gif
- sparkles.gif

The bot will randomly select a message from `messages.json` and upload the corresponding GIF file.
